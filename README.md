# 3D 可视化 / 启动动画

一套用**纯 CPU 软件光栅器**跑出来的 3D 线框渲染器，两个壳：

| 程序 | 形态 | 用途 |
|---|---|---|
| `3D\AuroraLauncher.exe` | 不透明全屏窗口 | 启动器的启动动画：极光天空 + 架空木构场景，播完自动退出 |
| `3D\PhysxPUBGMock.exe` | 透明穿透窗口（叠桌面） | 桌面叠层：实时渲染 + 鼠标转视角 + 射线命中 |

两个 exe 共用同一份场景、同一套渲染管线，区别只在窗口外壳和是否播放极光。

---

## 快速开始

**看启动动画**

```
双击 3D\AuroraLauncher.exe
```

全屏播放 9 秒，按 `ESC` / `空格` / 点一下鼠标可以立刻跳过，播完自动退出。

**看桌面叠层**

```
双击 3D\PhysxPUBGMock.exe
```

桌面上下叠一层半透明的 3D 场景。按住**鼠标中键**拖动转视角，`F8` 退出。

## 构建

```
cd /d E:\workaddress\31\3D
build.cmd            编译两个目标
build.cmd aurora     只编启动动画
build.cmd mock       只编桌面叠层
```

不依赖 `vcvars64.bat`（它会调 `reg.exe`，被本机策略拦），编译脚本里直接写死 `INCLUDE` / `LIB`。

需要：MSVC 14.44.35207 + Windows SDK 10.0.26100.0。换机器要改 `build.cmd` 顶部那三行路径。

## 这一版里做了什么

- 房间改成**架空木构**：4 根柱 + 柱顶圈梁 + 每面一个**倒三角斜撑**，地面抬高 140cm，地形起伏完整保留
- 地板铺 **5×5 瓷地板砖**，砖缝 2cm，缝里露出楼板
- 新增**极光天空**：按真实极光发射谱线配色（557.7nm 黄绿 / 427.8nm 蓝紫 / 630nm 品红），双层帘幕 + 竖直丝缕 + 星点
- 新增**启动动画**外壳：推近入场 → 缓慢环绕 → 淡出，全屏不透明，可跳过

## 已知限制

1. **软件渲染，帧率不高**。启动动画按 1600×900 渲染再拉伸到屏幕，空闲时约 36~38fps；系统有重负载（比如开着大型游戏）会掉到 20fps 左右。
2. **全屏时有独占全屏应用在前台，启动动画会被盖住**。`WS_EX_TOPMOST` 管不了独占全屏（游戏会绕过 DWM 合成）。正常桌面环境下不受影响。
3. **没有真正的 DMA 数据**。场景全部来自 `MockScene.h` 的合成几何，原工程的 `Offset.h` 里那套偏移是历史版本，接真机需要重新扫描（见 `实现方向.md`）。
4. 极光是**逐像素 CPU 算的**，没有用 GPU。要更高帧率得改成 D3D/OpenGL（见 `实现方向.md`）。
